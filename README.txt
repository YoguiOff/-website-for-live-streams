INSTALACIÓN EN GITHUB
1. Descomprime el ZIP.
2. Entra en tu repositorio de GitHub.
3. Pulsa Add file > Upload files.
4. Sube los cuatro archivos y la carpeta assets completa.
5. Asegúrate de mantener la estructura assets/yogi-banner.png y assets/yogi-avatar.png.
6. Pulsa Commit changes.
7. Espera unos minutos y recarga tu web.

No borres el repositorio ni cambies la configuración de GitHub Pages.
